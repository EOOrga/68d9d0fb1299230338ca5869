# BIEHLER JEAN

Flutter Android app for local business operations work: payroll reports,
appointment booking, compliance reporting, and procurement requests.

The app stores records on the device with `shared_preferences`. It does not use
accounts, remote APIs, analytics, advertising, or Android permissions.

Store materials are under `docs/`, and `web/` is a standalone static landing
page rather than Flutter web output.
